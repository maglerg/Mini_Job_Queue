1. Weather Automation — сбор и анализ погоды
Лучший вариант
Сервер каждые 1–5 минут запрашивает погоду из Open-Meteo и сохраняет результаты в PostgreSQL. API не требует ключа для обычного использования. 

Автоматизация: обнаруживать изменения прогноза, резкое падение температуры или повышение вероятности осадков.

Что продемонстрируешь: BackgroundService, HttpClient, периодические задачи, сравнение данных, уведомления через SignalR.

Сценарий легко показать сразу: можно вручную запустить проверку, а затем продемонстрировать работу автоматического цикла.

Источник: Open-Meteo API.


4. RSS Aggregator — автоматический сбор новостей
Пользователь добавляет RSS-ленты интересующих его сайтов, а сервер сам проверяет их по расписанию.

Автоматизация: обнаружение новых публикаций, устранение дубликатов, категоризация по ключевым словам и формирование подборки.

Что продемонстрируешь: несколько параллельных HTTP-запросов, очередь обработки, дедупликацию и фоновые задания.

Плюс: новые данные могут появляться в течение дня, поэтому демонстрация получается живой. Нужно учитывать условия конкретных источников и не копировать полные тексты статей без разрешения.
